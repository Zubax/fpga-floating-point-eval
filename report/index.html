Generated 2026-05-24T00:07:36+03:00. Mode: full. Target frequencies: Lattice ECP5 / Yosys + nextpnr: 100 MHz; Lattice ECP5 / Diamond: 100 MHz; AMD/Xilinx Spartan-7 / Vivado: 150 MHz.

Caveat. ZKF semantics differ from IEEE/FloPoCo around NaN, subnormals, signed zero, and exception encoding. This benchmark compares synthesized implementation cost and latency under matched exponent/significand widths. FloPoCo wF excludes the hidden bit, so ZKF WMAN=18/36 is compared with FloPoCo wF=17/35. FloPoCo 5.1 FPAdd, FPMult, and FPDiv do not expose a documented command-line option to disable NaN handling; the native FloPoCo format already does not support IEEE subnormals. Each target/toolchain tunes ZKF staging and FloPoCo generation parameters independently; the report shows the selected best candidate per library/operator/format using this policy: lowest latency among rows that pass the target frequency, then lowest resource use, then highest Fmax. If no candidate passes, the highest-Fmax failing candidate is shown and marked FAIL.
